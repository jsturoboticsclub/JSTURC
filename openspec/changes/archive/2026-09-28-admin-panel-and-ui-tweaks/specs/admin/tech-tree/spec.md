# Spec Delta

## Purpose

Allows administrators to edit the Curriculum Tech Tree nodes and content directly from the admin panel.

## ADDED Requirements

### Requirement: Admin can edit tech tree
The system SHALL allow authenticated administrators to add, edit, or remove nodes from the Curriculum Tech Tree.

#### Scenario: Edit tech tree node
- **WHEN** admin modifies a tech tree node's title or description and saves
- **THEN** the changes are reflected on the frontend Curriculum Tech Tree component
